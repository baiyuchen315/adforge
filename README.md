# AdForge 素材裂变 Agent Demo

完整解压 ZIP 后双击 `index.html` 即可运行，无需安装软件或联网。六张演示图片已直接内嵌在 HTML 中，不再依赖外部图片路径。

建议演示路径：

1. 点击“一键加载示例任务”，或自行上传/填写四类资料：商品与品牌信息、原始素材、素材结构信息和制作要求。
2. 根据项目需要增加自定义品牌或商品字段；输入结构并未写死。
3. 点击“开始多模态理解”，沿素材时间轴检查 Agent 的识别结果、来源、证据和置信度；处理资料冲突，并逐项设为“锁定、可变化或待确认”。
4. 进入“裂变策略”，先选择投放环境，再选择探索强度和本轮需要覆盖的创意方向。
5. 生成六个具有真实视觉差异的候选，查看父素材关系、变化假设、制作记录和自动质检结果。
6. 采用或拒绝候选，再进入人工审批。
7. 模拟投放后录入表现，查看 Agent 给出的继续、转向或限制使用建议，并从胜出素材生成第二代候选，验证素材血缘闭环。

说明：本 Demo 的表单、上传预览、要素确认、策略选择、候选审批和反馈决策均可操作；AI 理解、素材生成和投放数据使用模拟结果，不会调用外部模型、真实生成广告或修改投放预算。
